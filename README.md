# logic-backend-datalog

Default backend for [logic-protocol](https://github.com/egao1980/logic-protocol): pure Lisp, semi-naive evaluation with incremental maintenance on assert / retract, stratified negation, optional Dedalus-style time-step rules. Slice L0 of Track L.

Design: [cl-stack/docs/capabilities/logic.md](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/logic.md). Scaffold only; the first version lands through team-solve.
